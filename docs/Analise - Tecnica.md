# Análise Técnica — TechAssets

## Responsabilidades

O sistema foi organizado em módulos com responsabilidades específicas.

### Interface
Responsável pela interação com o usuário.

### Controller
Responsável por receber requisições e encaminhá-las.

### Service
Responsável pelas regras de negócio.

### Repository
Responsável pela persistência e consulta dos dados.

### Database
Responsável pelo armazenamento das informações.

## Coesão

A organização busca manter alta coesão,
concentrando responsabilidades relacionadas
dentro de cada módulo.

## Acoplamento

A arquitetura busca reduzir o acoplamento
entre os módulos por meio da separação
de responsabilidades.

## Melhoria

A principal melhoria proposta é separar
claramente as responsabilidades entre
Controller, Service e Repository.
